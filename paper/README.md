# arXiv Appendix Source

`appendix.tex` is the appendix source incorporated into the arXiv manuscript.
It is intended to be included by the main manuscript and is not a standalone
LaTeX document.

The computational artifact reproduces the figures and numerical tables
reported in Appendices A–I.

The software in this repository is governed by the root software license.
The manuscript source remains governed by the license selected for the arXiv
submission.
